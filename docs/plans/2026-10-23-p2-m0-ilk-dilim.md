**Goal:** En kısa yoldan uçtan uca çalışan bir döngü: Qwen2.5-Coder-3B-Instruct'ı Spider dev'in tamamında (1034 soru) prompt ile ölç → Spider train ile QLoRA (Unsloth + TRL) eğit → aynı 1034 soruda tekrar ölç → ilk Δ (McNemar p-değeri ile).

> **Revizyon (2026-10-23, bağımsız inceleme sonrası):** vLLM + LoRA Blackwell kontrolü Task 1'e taşındı; token düzeyinde prompt/mask testi eklendi; tam eğitimden önce uçtan uca duman testi (eğit → servis → eval) eklendi; ilk Δ tam dev'de + McNemar; sütun sırasını tolere eden ikinci EX; kaldığı yerden devam, `sample_rows`, `include_train_others`, `float_round_digits`, `explain-config`/`CONFIG.md`, alt paket README'leri ve pre-commit M1'e ertelendi.

## Review Focus

1. **Gold SQL hata veriyor / zaman aşımına uğruyor** → `gold_error`, EX paydasından çıkar, sayısı raporda. (Test: Task 4)
2. **Model birden çok ifade ya da yazma ifadesi üretiyor** (`SELECT 1; DROP TABLE t`) → yalnızca ilk ifade, salt okunur bağlantı yazmayı reddeder, DB dosyası değişmez. (Test: Task 3 + Task 4)
3. **Sonsuz/çok büyük sorgu** (recursive CTE, kartezyen çarpım) → `timeout` / `too_many_rows`, koşu takılmaz. (Test: Task 4)
4. **Eğitim prompt'u ile değerlendirme prompt'u token düzeyinde sapıyor** (chat template, `add_generation_prompt`, `<|im_end|>`, Unsloth şablon yaması) → eğitimde görülen prompt token'ları = vLLM'in `/tokenize` ile ürettiği token'lar; completion `<|im_end|>` ile biter; prompt label'ları -100. (Test: Task 6)
5. **Model doğru veriyi farklı sütun sırasıyla döndürüyor** → katı EX yanlış sayar; sütun sırasını tolere eden `ex_col_tolerant` ayrıca raporlanır, Δ'nın "Spider üslubu" kısmı görünür olur. (Test: Task 4)
